# Portfolio

The source for [jordan-christensen.com](https://jordan-christensen.com): an Xcode-themed developer portfolio, a Markdown blog, and the privacy policy and support pages for my App Store apps.

There's no database. Content is stored as JSON files, images as WebP, and a small Express server reads and writes them. Content is edited through Folio, a separate SwiftUI app that talks to the API.

## What's in here

| Folder | What it is |
|--------|------------|
| [`frontend/`](frontend) | The public site. React 19, Vite, Tailwind 3 and React Router 7, built as a static single-page app. |
| [`backend/`](backend) | The REST API for projects, posts, app pages and media uploads. Express 4 and TypeScript, with `sharp` converting uploads to WebP. |
| [`deploy/`](deploy) | A copy of the live `.htaccess`. |

## Features

- An Xcode look throughout, with light and dark themes
- Project and blog detail pages with a navigator sidebar and a scroll minimap
- Markdown posts with syntax highlighting
- A `>_` console with `ls`, `cd`, `open`, `whoami`, `contact` and tab completion
- Keyboard shortcuts: ⌘B for "Build Succeeded" and ⌘⇧K for "Clean Build Folder"
- A fake macOS crash report when a list fails to load, and a fake compiler error for 404s
- A sitemap, an RSS feed and per-page share previews, generated by the backend
- Responsive images, with 640 and 1280 px sizes made at upload

## Running it locally

You'll need Node 20.9 or later (CI uses 22).

```sh
# Backend, on port 3001
cd backend
cp .env.example .env   # then set API_SECRET
npm install
npm run dev

# Frontend, on port 5173 (proxies /api and /media to the backend)
cd frontend
npm install
npm run dev
```

The backend reads `API_SECRET` (the Bearer token for write requests) and a few optional overrides from `backend/.env`. See [`backend/.env.example`](backend/.env.example). Reads are public, so the site works without a token.

Content lives in `backend/data/` and `backend/public_html/media/`, and both are gitignored, so a fresh clone starts empty.

## Tests and checks

```sh
cd backend
npm test        # node:test + supertest
npm run build

cd frontend
npm run lint
npm test        # Vitest + Testing Library
npm run build
```

CI runs the same checks on every push to `main` and on pull requests, plus `npm audit`.

The backend also has a few maintenance scripts:

| Command | What it does |
|---------|--------------|
| `npm run regen` | Rebuilds the indexes, sitemap, feed and share pages |
| `npm run check` | Read-only integrity report: bad records, stale indexes, missing or unused media |
| `npm run media:derive` | Creates any missing 640/1280 px image sizes |
| `npm run smoke -- <url>` | Read-only checks against a deployed site |
| `npm run snapshot` | Downloads the live content as a backup |

## API

| Route | Description |
|-------|-------------|
| `GET /api/health` | Health check |
| `/api/projects` | List, nav, get, create, update, delete |
| `/api/posts` | List, nav, get, create, update, delete |
| `/api/apps` | Privacy policy and support pages for each app |
| `/api/media` | Image upload and delete |

`GET` requests are public. Writes need `Authorization: Bearer <API_SECRET>`. The full reference is in [`backend/DEVDOC.md`](backend/DEVDOC.md#api-reference).

## Deployment

The site runs on cPanel shared hosting: the frontend and media are served as static files, and the backend runs as a Node app under Phusion Passenger. Deploys are manual. See [`DEPLOY.md`](DEPLOY.md).
